# 🐾 Lumina Pets - Adoption Shelter Web App

An interactive, multi-page web platform for an animal shelter designed to showcase pets available for adoption, share the shelter's mission, and connect potential adopters with their new furry friends. Built with semantic HTML, modern CSS, vanilla JavaScript, and bundled with Vite.

[![Live Demo](https://img.shields.io/badge/demo-online-brightgreen?style=for-the-badge)](https://lumina-pets-web-ajdev.netlify.app/)
[![GitHub Repository](https://img.shields.io/badge/github-repo-black?style=for-the-badge&logo=github)](https://github.com/ArmandoJimenez-dev/Lumina-Pets-Web-js)


## ✨ Technologies

- HTML5 & CSS3
- JavaScript (ES6+)
- Vite (Multi-Page Application setup)
- FontAwesome & Google Fonts

## 🚀 Features

- **Multi-Page Architecture:** Structured navigation across Home (`index.html`), About Us (`about.html`), and Contact (`contact.html`) pages.
- **Dynamic Pet Gallery:** Pet grid rendered dynamically via JavaScript DOM manipulation for seamless UI updating.
- **Adoption Request Form:** Interactive contact form for prospective adopters to submit inquiries.
- **Responsive Layout:** Mobile-first layout with clean typography and custom CSS styling.
- **Vite MPA Integration:** Custom Rollup multi-entry configuration for fast development and optimized production builds.

## 📍 The Process

For my second portfolio project, I wanted to step up from single-page builds and practic configuring a Multi-Page Application (MPA) using Vite. Building **Lumina Pets** allowed me to refine semantic HTML structure, CSS layout techniques, and vanilla JavaScript DOM rendering.

I focused on maintaining clean file modularity, optimizing multi-page routing in Vite, and practicing proper asset management for images and modular scripts.

## 🚦 Running the Project

1. Clone the repository:
   git clone https://github.com/ArmandoJimenez-dev/Lumina-Pets-Web-js.git
2. Install dependencies:
   npm install
3. Run development server:
   npm run dev
4. Open http://localhost:5173 in your browser.
